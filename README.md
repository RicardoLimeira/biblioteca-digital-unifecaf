# Biblioteca Digital UniFECAF

Projeto acadêmico de Design Web desenvolvido com HTML5 e CSS3.

## Como executar
1. Extraia a pasta do projeto.
2. Abra `index.html` no navegador ou use a extensão Live Server no VS Code.
3. Para publicar, crie um repositório no GitHub e habilite GitHub Pages nas configurações.

## Estrutura
- `index.html`: estrutura semântica e conteúdo da página.
- `css/style.css`: cores, tipografia, componentes e media queries responsivas.
- `assets/imagens/`: diretório reservado para imagens locais, caso queira substituir as imagens externas.

## Observações
Os livros são exemplos ilustrativos, não representam um catálogo oficial confirmado. As imagens são carregadas de URLs externas do Unsplash e exigem conexão com a internet. O projeto é uma interface demonstrativa; não possui autenticação, pesquisa funcional ou empréstimo de livros.
